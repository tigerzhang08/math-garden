# 数字小花园

一款适合小学低年级的加减法练习网页。纯前端实现，不需要账号、服务器或第三方依赖。

## 本地打开

直接用浏览器打开 `index.html` 即可。

## 发布到 GitHub Pages

1. 将此目录中的文件提交到 GitHub 仓库的 `main` 分支。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/(root)` 目录，保存。
5. 等待 GitHub Pages 完成部署，再打开页面显示的地址。

项目没有构建步骤；题目生成、答题和成绩展示都在浏览器中完成。最近一次成绩保存在当前设备的浏览器本地存储中，不会上传到服务器。

## 功能

- 20 以内、100 以内不进退位、100 以内进退位三档练习
- 每轮 15 或 20 道随机题，混合加法与减法
- 触屏数字键盘，也支持实体键盘输入
- 即时答题反馈、简短算式提示和错题复习
- 手机竖屏与平板横屏响应式布局
